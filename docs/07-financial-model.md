# GroupDrive India: Financial Model

Illustrative unit economics. Replace every assumption with measured data as you learn.

| Assumption | Value |
|---|---|
| Price per cars delivered (INR) | 6,000 |
| Volume Y1 / Y2 / Y3 (cars delivered) | 500 / 5,000 / 25,000 |
| Variable cost per unit (INR) | 900 |
| Revenue shared out (airline/partner) | 0% |
| Acquisition cost per unit (INR) | 800 |
| Fixed costs Y1 / Y2 / Y3 (INR) | 7,000,000 / 22,000,000 / 55,000,000 |

Run `python finance/model.py` for the projected profit table. Edit `PARAMS` in that file to test scenarios.
